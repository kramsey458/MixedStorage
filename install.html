Install MixedStorage

It takes a couple of minutes: extract one folder, enable two mods, and restart the game.

Requirements

Timberborn 1.1.2.4

The version MixedStorage is built and tested against. Other versions aren't guaranteed.

Harmony 2.4.1 or newer

A required mod. Get it from the Steam Workshop if you don't have it.

BeaverBuddies (optional)

Only for multiplayer. Single-player doesn't need it.

Step by step

  1. Download the ZIP

    Open the latest release and, under Assets, choose MixedStorage-vX.Y.Z.zip. Don't pick Source code.

    Download the mod

  2. Close Timberborn and extract

    With the game closed, extract the ZIP's MixedStorage folder into your Timberborn Mods folder. On Windows that's normally Documents\Timberborn\Mods.

  3. Check the folder layout

    You should end up with exactly this. Avoid an extra nested MixedStorage folder.

    Documents\Timberborn\Mods\
└─ MixedStorage\
   ├─ README.md
   └─ version-1.1\
      ├─ manifest.json
      └─ MixedStorage.dll

    Confirm that Documents\Timberborn\Mods\MixedStorage\version-1.1\manifest.json exists.

  4. Install Harmony if needed

    MixedStorage requires Harmony 2.4.1 or newer. If it isn't installed yet, subscribe to it on the Steam Workshop.

  5. Enable and restart

    Start Timberborn, enable Harmony and MixedStorage in the mod manager, and restart when prompted.

Check it works

Load a save and select a supported warehouse or pile (see the supported buildings). You should see a Storage Allocation panel in the building's window.

Not there? MixedStorage logs a line at startup. Search Player.log for [MixedStorage] and look for:

[MixedStorage] <version> loaded; warehouse and pile allocations for Timberborn 1.1.2.4.

The log is normally in %USERPROFILE%\AppData\LocalLow\Mechanistry\Timberborn. If the panel is still missing, the troubleshooting guide covers it.

Your first mixed storage building

  1. Select a building

    Click a supported warehouse or pile.

  2. Find your goods

    Look in Storage Allocation. Use Search if the list is long.

  3. Enter percentages

    Type a percentage for each good you want, and leave everything else at 0%.

  4. Make it 100% and apply

    The total must be exactly 100%. Then click Apply 100%. For a 1,200-capacity warehouse, entering 50 for carrots and 50 for gears allows 600 of each.

Edits are drafts until you click Apply. The summary at the top keeps showing the applied settings and actual stock while you edit, search, or filter. Normal hauling rules decide when goods arrive.

The controls

ControlWhat it does
MaxSets that good to 100% and all others to 0%. Click Apply to confirm.
× beside a percentageResets that good's draft percentage to 0%.
Clear allClears draft percentages. Current allocations stay active until you apply a valid replacement.
RevertDiscards edits and restores the current settings.
Allocated goods onlyShows goods with a nonzero draft percentage.
Copy allocationsCopies a valid draft totaling 100%.
Paste allocationsPastes copied percentages into another building's draft. Click Apply there to confirm.

Percentages allow two decimal places. Copy and paste adjusts item limits to the destination's capacity, and the destination must accept every copied good with a nonzero percentage. Stock, hauling mode, and hauler priority are not copied. Copied settings last only for the current game session.

Upgrading

From an earlier version: with the game closed, replace the existing MixedStorage files with the new ones. Existing MixedStorage allocations are preserved.

Coming from v0.4.x or earlier?

Remove or disable MixedStorage-BeaverBuddies, the old separate add-on. Its functionality is now built in, and leaving it enabled causes a startup error. Keep BeaverBuddies itself if you play multiplayer.

Multiplayer with BeaverBuddies

  • Install the same MixedStorage version on every computer, alongside matching BeaverBuddies versions and Harmony.
  • Enable BeaverBuddies as usual. MixedStorage automatically turns on its bundled integration.
  • There is no separate MixedStorage multiplayer download.
  • After upgrading, restart every computer's game and start a fresh multiplayer session.

The multiplayer integration was developed against BeaverBuddies Stability Preview for Timberborn 1.1. Other builds aren't guaranteed to be compatible.
