Install MixedStorage

It takes a couple of minutes: extract one folder, enable two mods, and restart the game.

Requirements

  • Timberborn 1.1.2.4

    The version MixedStorage is built for. Other versions aren't guaranteed.

  • Harmony 2.4.1 or newer

    A required mod, from the Steam Workshop.

  • BeaverBuddies Stability Fork

    Optional, only for co-op.

Step by step

  1. Download the ZIP

    Open the latest release and, under Assets, choose MixedStorage-v1.2.0.zip. Don't pick Source code.

    Download v1.2.0

  2. Close Timberborn and extract

    With the game closed, extract the ZIP's MixedStorage folder into Documents\Timberborn\Mods. If your Documents folder is in OneDrive, use OneDrive\Documents\Timberborn\Mods.

    Windows' Extract All adds an extra folder named after the ZIP. Move the MixedStorage folder inside it into Mods.

  3. Check the folder layout

    You should end up with exactly this:

    Documents\Timberborn\Mods\
└─ MixedStorage\
   ├─ README.md
   └─ version-1.1\
      ├─ manifest.json
      └─ MixedStorage.dll

    Check that there's no extra folder around MixedStorage and no second MixedStorage inside it.

  4. Install Harmony if needed

    If you don't have Harmony 2.4.1 or newer, subscribe to it on the Steam Workshop.

  5. Enable and restart

    Start Timberborn, enable Harmony and MixedStorage in the mod manager, and restart when prompted.

Check it works

Load a save and select a supported warehouse or pile. Its window should show a Storage Allocation panel.

Not there? Search Player.log for [MixedStorage]. A working install logs this line at startup:

[MixedStorage] <version> loaded; warehouse and pile allocations for Timberborn 1.1.2.4.

On Windows, the log is in %USERPROFILE%\AppData\LocalLow\Mechanistry\Timberborn. Still missing? See the troubleshooting guide.

Your first mixed storage building

  1. Select a building

    Click a supported warehouse or pile.

  2. Find your goods

    Look in Storage Allocation, or use Search.

  3. Enter percentages

    Type a percentage for each good you want. Leave the rest at 0%.

  4. Make it 100% and apply

    When the total is exactly 100%, click Apply 100%. In a 1,200-capacity warehouse, 50 carrots and 50 gears allow 600 of each. Apply grayed out? Here's why.

To make a building store nothing, set every good to 0% (Clear all does this) and click Apply: store nothing. Stock already there stays and can be hauled out.

Edits are drafts until you click Apply. While Apply would change the building, it has an orange ring.

The controls

ControlWhat it does
MaxSets that good to 100% and every other good to 0%.
× beside a percentageSets that good to 0%.
Clear allSets every good to 0%.
RevertDiscards your edits.
Allocated goods onlyShows only goods above 0%.
Copy allocationsCopies a valid 100% split.
Paste allocationsPastes it into another building. Limits follow that building's capacity.

Percentages allow two decimal places. Paste works only if the building accepts every copied good. Stock, hauling mode and hauler priority aren't copied, and the copy is kept until you close the game.

Upgrading

With the game closed, replace the MixedStorage files with the new ones. Your allocations are kept. In co-op, everyone updates together.

Still have MixedStorage-BeaverBuddies?

MixedStorage includes what that old add-on did, and leaving it enabled causes a startup error. Remove or disable it, but keep BeaverBuddies itself for co-op.

Multiplayer with BeaverBuddies

  • Co-op needs the latest BeaverBuddies Stability Fork on every computer.
  • Every player needs the same MixedStorage version, Stability Fork build and game version.
  • There's no separate multiplayer download. Co-op support is built in and turns on by itself.
  • After upgrading, everyone restarts the game and starts a fresh session.

Removing MixedStorage

Close Timberborn, then disable MixedStorage in the mod manager or delete its folder. In saves that used it, each mixed building goes back to one good: the one with the largest share. Haulers move the other goods out, as when you change a warehouse's good in the base game.
